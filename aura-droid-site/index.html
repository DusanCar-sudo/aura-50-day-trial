Features

Everything Aura,
on Android.

Aura Droid brings the full power of Aura Code to your Android device — no desktop required.

🤖
Full Aura Integration
Connect to your local Aura instance or a remote server. Same autonomous agent, same model-agnostic power, now in your hand.
💬
Claude-like Chat Interface
A conversational UI that feels like Claude. Message history, streaming responses, and a clean reading experience for code and prose alike.
📁
Session Management
Create, pin, archive, and delete chat sessions. Your conversations stay organized — pick up exactly where you left off.
🔧
Three Modes
Switch between Coder, Gazelle, and Architect modes. Each tailors Aura's behavior — file ops and diffs, fast iteration, or planning and design.
📝
Markdown + Syntax Highlight
Render markdown messages with full syntax highlighting. Tables, lists, code blocks, and diffs — all rendered natively.
🌐
Wi-Fi Pairing
Pair your phone with your desktop over the local network. One identity handshake, then you're connected — no cloud, no accounts.
⚙️
Configurable
Set up API keys, models, providers, and behavior settings. Connect to any LLM provider — DeepSeek, Claude, GPT, Gemini, and more.
🌙
Dark / Light Theme
Material 3 design with automatic theme switching. Comfortable coding at 2 AM or on a sunny balcony — your eyes decide.
Architecture

Three pillars.
One ecosystem.

Built on a clean, layered architecture — from the UI down to the network layer.

01
Chat Interface
Claude-like conversational UI with message history, streaming responses, and markdown rendering. Built entirely in Jetpack Compose with Material 3 theming.
JETPACK COMPOSE
02
Session Management
Create, pin, archive, and delete chat sessions. Room database with Flow-based reactive queries keeps your conversation list always up to date.
ROOM · FLOW
03
Network Layer
Retrofit + OkHttp for HTTP, with coroutines for async. Handles streaming responses, connection retries, and transparent routing to any Aura-compatible endpoint.
RETROFIT · COROUTINES
How it works

Three steps.
Zero friction.

01
Pair
Open the app, go to Settings, and scan or enter the pairing code from aura serve --lan on your desktop.
02
Configure
Set your project, model, and provider. The identity handshake ensures only your phone can talk to your desktop — no cloud, no accounts.
03
Code
Start a new session, pick your mode — Coder, Gazelle, or Architect — and let Aura read, plan, execute, and verify right from your phone.
bash — pair & connect
# On your desktop — start Aura with LAN access
$ aura serve --lan

# Output:
→ LAN server running at 100.69.237.108:7337
→ Identity: 3FBC3939

# In Aura Droid — paste the address and identity
$
Stack

Built with modern Android.

100% Kotlin, fully declarative UI, and a reactive data layer — the way Android development should be.

K
Kotlin
100% Kotlin codebase. Null-safe, coroutine-ready, and idiomatic throughout.
JC
Jetpack Compose
Modern declarative UI. Every screen is a composable — reactive, testable, and fast.
M3
Material 3
Latest Material Design components with dynamic color and adaptive layouts.
HI
Hilt
Dependency injection done right. Scoped, testable, and zero boilerplate at the call site.
DB
Room
Local database for sessions and messages. Flow-powered reactive queries keep the UI in sync.
CF
Coroutines & Flow
Reactive programming end to end. Structured concurrency, no callbacks, no leaks.
